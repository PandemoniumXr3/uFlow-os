# uFlow 🧠🍽🌍  
> A Modular Food Decision & Behavioral Architecture  
> Context Before Recipes. Structure Before Impulse.

---

## 🚀 What is uFlow?

uFlow is a modular web application that helps people make structured, safe, and intelligent food decisions.

Unlike traditional recipe apps, uFlow does not immediately suggest meals.

It first understands context.

It combines:
- Inventory awareness
- Personal tolerances (IBS / PDS / ARFID / allergies / taste)
- Diet preferences
- Mental state & flow
- Time constraints
- Budget intelligence
- Expiration awareness
- Behavioral design
- Modular feature control

uFlow is not just a recipe app.  
It is a **Personal Food Operating System**.

---

# 🧠 Core Philosophy

Most food apps:

- Show recipes immediately
- Ignore mental state
- Ignore tolerances
- Ignore budget
- Ignore inventory
- Ignore decision fatigue

uFlow asks first.

Before generating suggestions, it asks:

- How are you feeling?
- What do you NOT want?
- Warm or cold?
- Safe or something new?
- Familiar or experimental?
- Where are you?
- How much time do you have?
- What is your budget?
- What do you have in stock?
- What expires soon?
- Any allergies?
- Any intolerances?
- Active diet type?
- Energy level?

If a user does not want to answer certain questions, modules can simply be turned off.

Only after building context does uFlow generate meal suggestions.

# 🏗 System Architecture (Layered Design)

uFlow is designed in structured layers to allow controlled growth.

---

## 🔹 Layer 1 – Context Engine (MVP Core)

The entry point of every session.

Builds a temporary "Food State" based on:
- Mood
- Cravings
- Warm / cold preference
- Safe / new preference
- Time availability
- Budget range
- Location
- Energy level

This prevents impulsive, random decision-making.

---

## 🔹 Layer 2 – Core Functional Modules (MVP)

These modules form the initial release.

### 📦 Inventory Module
- Add products manually
- Track quantities
- Detect near-expiration items
- Mark products as used
- Suggest meals to reduce waste

### 🍽 Recipe Module
- Add personal recipes
- Save favorite recipes
- Generate recipes based on:
  - Current stock
  - Time available
  - Flow state
  - Tolerances
  - Diet
  - Budget
- Show missing ingredients
- Suggest ingredient swaps

### 🧬 Tolerance & Allergy Module
- Store allergies
- Store intolerances (IBS / PDS / ARFID)
- Block ingredients automatically
- Enable "Safe Meals Only" mode

### 🥗 Diet Module
- Vegan
- Vegetarian
- Pescatarian
- High-protein
- Custom diet profiles
- Temporary diet modes

### 🛒 Grocery Module
- Automatic shopping list generation
- Missing ingredient detection
- Expiration-priority shopping
- Editable before checkout

These form the practical starting system.

---

## 🔹 Layer 3 – Optimization Modules (Phase 2)
